## [[Abstraction]]

➤ [[Abstraction]]: It means hiding unnecessary details and  
Showing only the essential features of a  
System. Ex:- Calculator.

• Focuses only on what an object or modules does,  
not how it does it.

• Reduce Complexity.

• Make Software easier to understand and maintain.

### [[Advantages of Abstraction]]

→ Advantages:

I) Reduce Complexity III) Make Maintenance easier  
II) Improves readability IV) Encourages Code reuse

---

## [[Decomposition]]

➤ [[Decomposition]]: It is the process of breaking a large, Complex,  
Problems into Smaller, manageable modules or  
Components. Ex:- Order module (Breaks into modules)

→ Each module Performs a Specific task.

• Smaller modules are easier to design, test, debug  
and maintain.

• Different developers Can work on different modules  
Simultaneously.

### [[Advantages of Decomposition]]

→ Advantages:

I) Simplifies Problem Solving III) Make testing easier  
II) Support teamwork & Parllel IV) Improves maintainability  
development.
